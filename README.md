# Project Wendy - Mental Wellness Infrastructure Presentation

A comprehensive React-based presentation showcasing the Project Wendy mental wellness platform for India's startup founders.

## Features

- **10 Professional Slides** covering all aspects of the Wendy platform
- **PDF Download** capability with high-quality rendering
- **Brand-Consistent Design** using terracotta, sage, and warm grey color palette
- **Minimalist Line Art** illustrations integrated throughout
- **Responsive Layout** optimized for 1280x720 presentation format

## Quick Start

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The presentation will open automatically in your browser at `http://localhost:3000`

### Generating PDF

1. Once the application is running, click the **"📥 Download PDF"** button in the top-right corner
2. The PDF will be automatically generated and downloaded to your computer
3. The PDF will be named: `Project-Wendy-Wellness-Platform.pdf`

## Slide Structure

1. **Cover Slide** - Project introduction with three pillars
2. **The Reality** - Building at speed, breaking the builders
3. **The Invisible Cage** - The founder's emotional struggles
4. **The Solution** - Three-pillar framework (Content, Community, Care)
5. **Content Pillar** - Making vulnerability visible
6. **Community Pillar** - Founder Forums
7. **Care Pillar** - Professional therapeutic support
8. **The Missing Layer** - Emotional infrastructure visualization
9. **The Ecosystem Vision** - Tree and roots metaphor
10. **Join Us** - Call to action with contact information

## Color Palette

- **Terracotta**: `#D4735E` - Primary accent, warmth, human connection
- **Sage**: `#9CAF88` - Secondary accent, growth, calm
- **Warm Grey**: `#A8A29E` - Neutral, grounding
- **Background**: `#F5F5F0` - Soft, warm neutral

## Design Principles

- Minimalist line art with breathing space
- Abstract humanity (no demographic markers)
- Organic shapes mixed with structural elements
- Muted tones for calm, contemplative mood
- Dignity over drama

## Customization

To modify content, edit `/wendy-presentation.jsx`:
- Each slide is a separate div with `pageBreakAfter: 'always'`
- Colors are defined inline for easy modification
- Image URLs can be replaced with your own assets

## Technical Details

- **Framework**: React 18
- **Build Tool**: Vite
- **PDF Generation**: html2pdf.js
- **Fonts**: Roboto (body), Lora (headings)
